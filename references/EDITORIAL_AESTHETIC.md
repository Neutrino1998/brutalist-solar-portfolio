# Editorial Aesthetic (Constructivist / Brutalist Grid) Reference

This document summarizes the **Editorial Aesthetic** style applied to the application and saved as reference in `references/editorial-aesthetic.html`.

## 🎨 Color Palette

| Token / Usage | Hex Code | Description |
|---|---|---|
| **Dark Canvas Background** | `#121212` | Deep charcoal / near black base canvas |
| **Glow / Grid Accent** | `#1A1A1A` / `#333333` | Radial gradient core and geometric grid lines |
| **Accent Red** | `#BE2E21` | Bold constructivist red (buttons, highlights, active states) |
| **Warm Off-White Text** | `#DED8C4` | Vintage paper / parchment tone for main typography |

## 📐 Layout & Visual Characteristics

- **Grid System**: 3D spatial grids combined with crisp 2D line overlays (`border-[#333]`).
- **Typography**: Heavy uppercase headings with tight tracking (`tracking-tighter`), contrasting with small monospace/sans metadata text (`tracking-widest`).
- **Geometric Badges**: Rotated diamond markers, circular nodes, and clean bordered blocks.
- **Aesthetic Vibe**: Soviet / Constructivist avant-garde meets modern brutalist WebGL interactive portfolio.
